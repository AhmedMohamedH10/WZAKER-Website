# موقع وذكر (WZAKER)

```
index.html        الصفحة الرئيسية
css/style.css     الألوان والخطوط والحركة
js/config.js      الإعدادات (اسم المستودع على GitHub)
js/main.js        جلب روابط التحميل تلقائياً من GitHub
js/challenge.js   تحدي التسبيح (الواجهة والعد والمزامنة)
css/challenge.css شكل قسم التحدي
admin.html        لوحة التحكم: فائزين + مسابقة + لاعبين + إحصائيات (محمية بـ ADMIN_KEY)
functions/api/    السيرفر الصغير للتحدي (Cloudflare Pages Functions)
sql/              ملفات قاعدة البيانات D1: schema.sql (قاعدة جديدة) و migrate-v*.sql (ترقية قاعدة قديمة)

assets/img/       الصور (الاسم، الأيقونة، favicon)

```

قبل الرفع: افتح `js/config.js` وغيّر `OWNER/wzaker` لاسم حسابك واسم المستودع.
الرفع على Cloudflare Pages: Build command فاضي، Output directory = `/`.

## تشغيل تحدي التسبيح (مرة واحدة)
العد بيشتغل ومحفوظ في المتصفح من غير سيرفر. علشان لوحة الترتيب والغرف تشتغل:
1. ارفع الفولدر ده على مستودع GitHub، وفي Cloudflare Pages اختار Connect to Git (مجلد `functions` بيتبني تلقائياً بالطريقة دي بس، مش بالرفع اليدوي).
2. من Workers & Pages > D1 اعمل قاعدة بيانات اسمها `wzaker`، وشغّل محتوى `schema.sql` في الـ Console بتاعها.
3. من إعدادات مشروع Pages > Bindings أضف D1 database باسم المتغير `DB` واختار القاعدة، وبعدها أعد النشر.

لو كنت شغّلت `schema.sql` قبل كده: شغّل بس آخر 3 أسطر فيه (جدول `visitors`) علشان إحصائيات الزائرين تشتغل.

## دخول جوجل + المسابقة (v3)

**1) قاعدة البيانات:** في D1 Console شغّل `migrate-v3.sql` ثم `migrate-v4.sql` (رابط الإحالة) ثم `migrate-v5.sql` (المسابقة التلقائية) ثم `migrate-v6.sql` (حفظ إيميل اللاعب) ثم `migrate-v7.sql` (تحكم الأدمن في المسابقة) ثم `migrate-v8.sql` (الهدف اليومي) مرة واحدة لكل واحد (لو القاعدة جديدة خالص، `sql/schema.sql` فيه كل حاجة).

**2) Google Cloud:** OAuth consent screen (External + Publish app) ثم OAuth client ID من نوع Web application، وفي Authorized JavaScript origins حط `https://wzaker.site`. حط الـ Client ID في `js/config.js`.

**3) Cloudflare Pages > Settings > Variables and Secrets:**
- `GOOGLE_CLIENT_ID` = نفس الـ Client ID.
- `SESSION_SECRET` = كلمة سر عشوائية طويلة (32+ حرف) كـ Secret. لو غيّرتها كل الناس هتتسجل خروج.
- `TURNSTILE_SECRET` (اختياري، بس موصى بيه ضد البوتات): من Cloudflare > Turnstile اعمل Widget لدومينك، حط الـ Site Key في `js/config.js` مكان `TURNSTILE_SITEKEY`، والـ Secret Key هنا.
- أعد النشر بعدها.

**4) مَكْرُمَةُ ذِي الأَلْف (تلقائية، مفيش حاجة تعملها):**
- كل خميس الساعة 10:00 مساءً **بتوقيت بلد اللاعب**. السيرفر بيعرف بلد اللاعب من Cloudflare (حسب الـ IP) وبيعمل الجولة لوحده أول ما حد يفتح الصفحة، من غير Cron ولا إدخال يدوي. اللي ليهم نفس فرق التوقيت (مثلاً مصر والسعودية في الصيف) بيبقوا في جولة واحدة، وكل جولة ليها فايز مستقل.
- الجولة **مالهاش مدة**: بتتقفل بأول واحد يبلغ 1000 تسبيحة، واسمه بيتسجل في «لوحة المكرَّمين» (بالاسم والبلد والمدة). بعدها اللاعبين بيشوفوا الفايز وعدّ تنازلي لخميس الجاي، وبيقدروا يدخلوا الجولة الجاية بدري. لو محدش فاز لحد خميس الجاي، الجولة الجديدة بتحل محلها.
- **أول جولة** مش بتبدأ قبل 26 نوفمبر 2026 (ثابت `C_LAUNCH`). قبل كده الناس بتشوف عدّ تنازلي بس.
- التكريم هو الاسم في اللوحة. والفايز بيظهرله نموذج يكتب فيه وسيلة تواصل (رقم أو حساب)، ومعاه **24 ساعة بس من لحظة فوزه** (ممكن يعدّل الرقم جواها)، وبعدها النموذج بيختفي. الرقم **مش بيظهر للعامة**، وبتشوفه إنت بس من D1 Console بالأمر ده:
```sql
SELECT p.name, s.contact, s.cc, datetime(s.finished_at/1000,'unixepoch') AS won_utc
FROM contest_scores s JOIN players p ON p.id=s.pid
WHERE s.finished_at IS NOT NULL AND s.status<>'rejected' ORDER BY s.finished_at DESC LIMIT 20;
```
لو `contact` فاضي يبقى الفايز لسه ما كتبش رقمه (أو المهلة خلصت).
- الثوابت في أول قسم المسابقة في `functions/api/[[route]].js`: `C_TARGET` (الهدف)، `C_WEEKDAY` (اليوم: الخميس = 4)، `C_HOUR` (الساعة، 22 = 10 مساءً)، `CLAIM_MS` (مهلة كتابة الرقم)، `C_LAUNCH` (تاريخ أول جولة).
- النشر لازم يكون من Git (زي ما فوق) علشان `functions` تتبني، وتأكد إن `migrate-v5.sql` اتشغّل وإلا قسم المسابقة مش هيظهر.

**لوحة الأدمن (بديل تليجرام، وممكن تشتغل معاه):** صفحة `https://wzaker.site/admin.html` بتعرض آخر 50 فايز: الاسم، البلد، المدة، الرقم اللي كتبه (مع زر نسخ وزر واتساب لو رقم صالح)، إيميل جوجل، وحالة المهلة (منتظر الرقم / كتب رقمه / المهلة خلصت).
1. شغّل `migrate-v6.sql` في D1 Console (بيضيف عمود الإيميل).
2. في Cloudflare Pages > Settings > Variables and Secrets أضف `ADMIN_KEY` كـ Secret: كلمة سر عشوائية طويلة (16 حرف على الأقل، الأفضل 32+). أعد النشر.
3. افتح `/admin.html` وحط المفتاح. بيتحفظ لحد ما تقفل التبويب، وزر «خروج» بيمسحه.
- من غير `ADMIN_KEY` اللوحة مقفولة (503). المفتاح الغلط بيتأخر ردّه ثانية تقريباً. الصفحة مش بتظهر في جوجل (noindex).
- الإيميل بيتحفظ لكل من يدخل بجوجل، وبيظهر في اللوحة للفايزين بس. حدّث سياسة الخصوصية لو عندك واحدة.
- الصفحة بتعيد التحميل لوحدها كل دقيقة وهي مفتوحة.

**تبويبات لوحة الأدمن (v5 من اللوحة، من غير أي migration جديد):**
- **الفائزون:** كل بطاقة فايز فيها مؤشرات مراجعة: السرعة (متوسط تسبيحة/ثانية في الجولة)، الانتظام (رقم صغير = سرعة ثابتة زي الآلة، وده تقدير مش حكم)، وعدد الحسابات التانية اللي دخلت من نفس الشبكة (بصمة IP مش الـ IP نفسه، وممكن تتكرر بالغلط من واي فاي أو شبكة موبايل مشتركة). وزرار **استبعاد وحظر**: بيحط الفايز «مستبعد» وبيحظر اللاعب ويلغي جلسته، والجولة بترجع مفتوحة لباقي المتسابقين.
- **المسابقة:** تحت الحلقة قائمة بكل المتسابقين في الجولة (الاسم، البلد، التقدم ناحية الهدف)، والفايز عليه علامة «★ الفائز». كل منطقة زمنية ليها جولتها، فيه قائمة اختيار فوق لتغيير الجولة المعروضة. بتتحدث كل 10 ثواني وانت فاتح التبويب.
- **اللاعبون:** بحث بالاسم أو الإيميل (أو أعلى 30 لو البحث فاضي)، وزرار «المحظورون» لعرضهم بس، وحظر / فك حظر لأي لاعب.
- **الإحصائيات:** الزوار (متصلون الآن، بيسبّحوا الآن، جدد وناشطين آخر 24 ساعة، الإجمالي، اللي جاءوا بإحالة) واللاعبين (الإجمالي، بأسماء، دخلوا بجوجل، محظورون). بتتحدث كل 10 ثواني.
- **حماية المفتاح:** بعد 5 محاولات غلط من نفس الشبكة اللوحة بتتقفل 15 دقيقة (حتى لو كتبت المفتاح الصح)، والدخول الصح بيصفّر العدّاد. بتشتغل بجدول `settings` (من `migrate-v7.sql`)، ولو مش موجود بيفضل التأخير ثانية بس. مش بتمنع حد بيغيّر الشبكة كل مرة، فلو عاوز حماية أقوى استخدم Cloudflare Access أو Rate Limiting على `/api/admin/*`.
- **تنضيف الزوار:** السيرفر بيمسح لوحده (بشكل عشوائي مع النبضات) الزوار اللي ما سبّحوش وغايبين أكتر من 90 يوم. عدد المحذوفين بيتحفظ في `settings` (`v_pruned`) وبيتضاف لعدّاد الزوار، فالرقم المعروض ما ينزلش (تقريبي: زائر قديم لو رجع بيتعدّ مرة تانية). لو `settings` مش موجود مفيش حذف خالص.
- **Turnstile:** لازم تضبط الاتنين مع بعض: `TURNSTILE_SECRET` في Cloudflare و`TURNSTILE_SITEKEY` في `js/config.js`. لو ضبطت السر بس، الناس هتشوف «إعداد التحقق غير مكتمل» ومحدش هيقدر يدخل المسابقة.
- لو استبعدت فايز ولاعب تاني كان وصل الهدف بعده، هو اللي بياخد الفوز عند أول مزامنة جاية منه (وقت فوزه بيتسجل وقتها مش وقت وصوله الفعلي).

**التحكم في المسابقة من لوحة الأدمن (تشغيل في أي وقت أو جدولة):** في `/admin.html` تبويب «المسابقة» (محتاج `migrate-v7.sql`):
- **ابدأ الآن:** بتبدأ جولة فوراً لكل الناس في نفس اللحظة، بالهدف اللي تكتبه (من 10 لـ 100000، والافتراضي 1000). بتحل محل أي جولة شغالة.
- **جدولة:** اختار تاريخ وساعة (بتوقيت جهازك، والموقع بيحوّله لموعد واحد لكل العالم). لحد الموعد الناس بيشوفوا عدّ تنازلي. أقل مدة 2 دقيقة من دلوقتي وأقصاها سنة. ممكن تلغي أي جدولة قبل ميعادها.
- **إنهاء جولة شغالة:** زرار «إنهاء الجولة» جنب الجولة اليدوية الشغالة (لو لسه محدش فاز).
- **إيقاف الأسبوعي:** بيوقف جولات الخميس التلقائية. وقتها المسابقة بتظهر بس لما تبدأ أو تجدول جولة يدوية، وغير كده القسم بيختفي من الموقع. «تشغيل الأسبوعي» بيرجّعها.
- الجولة اليدوية بتفضل مفتوحة لحد ما حد يفوز، أو لحد ما تلغيها، أو ييجي خميس جديد (لو الأسبوعي شغال) فتحل الجولة الأسبوعية محلها، أو تبدأ جولة يدوية تانية.
- الفايز في الجولات اليدوية بيتعامل زي الأسبوعية: بيظهر في لوحة المكرَّمين وفي قائمة الفائزين، وعنده 24 ساعة لكتابة رقمه.
- لو `migrate-v7.sql` ما اتشغّلش، الموقع بيكمّل أسبوعي عادي واللوحة بتقولك تشغّله.
- للتجربة: اعمل جولة «ابدأ الآن» بهدف صغير (مثلاً 10) وجرّب بنفسك، ثم «إنهاء الجولة». نتائج التجربة بتفضل في القاعدة، فامسحها لو عاوز: `DELETE FROM contest_scores; DELETE FROM contest; DELETE FROM contest_manual;`

**إشعارات تليجرام (اختياري، موصى بيه):** علشان اسم الفايز ورقمه يوصلوك على موبايلك أول ما يحصلوا، بدل ما تفتح D1:
1. في تليجرام افتح `@BotFather` وابعتله `/newbot`، واختار اسم، وهيديك **توكن** (شكله `123456:ABC...`).
2. افتح البوت الجديد وابعتله أي رسالة (مثلاً "hi").
3. افتح في المتصفح `https://api.telegram.org/botالتوكن/getUpdates` (بدّل `التوكن` بتاعك). هتلاقي `"chat":{"id":123456789` — الرقم ده هو الـ Chat ID.
4. في Cloudflare Pages > Settings > Variables and Secrets أضف: `TELEGRAM_BOT_TOKEN` (كـ Secret) و `TELEGRAM_CHAT_ID`، وأعد النشر.
بعدها هتجيلك رسالتين: 🏆 لما حد يفوز (الاسم والبلد والمدة)، و📞 لما الفايز يكتب رقمه (الاسم والرقم). لو الإشعار فشل لأي سبب، الموقع بيكمل عادي والرقم يفضل محفوظ في D1 وتقدر تجيبه بالأمر اللي فوق.

**5) مراجعة الفايز (اختياري):**
```sql
SELECT s.pid, p.name, s.status, datetime(s.finished_at/1000,'unixepoch') AS finished_utc,
       (s.finished_at - s.first_sync)/1000.0 AS seconds,
       ROUND(c.target*1000.0/(s.finished_at - s.first_sync),2) AS taps_per_sec,
       s.n_b AS batches,
       ROUND((s.s_r2/s.n_b - (s.s_r/s.n_b)*(s.s_r/s.n_b)) / ((s.s_r/s.n_b)*(s.s_r/s.n_b)),3) AS cv2,
       s.ip_h, s.contact
FROM contest_scores s JOIN players p ON p.id=s.pid JOIN contest c ON c.id=s.contest_id
WHERE s.finished_at IS NOT NULL AND s.n_b>0 ORDER BY s.contest_id DESC, s.finished_at;
```
- `taps_per_sec` فوق حوالي 7 باستمرار مشبوه. السيرفر مش بيقبل أكتر من حوالي 9 في الثانية أصلاً.
- `cv2` قريب من صفر (أقل من 0.01) يعني سرعة ثابتة بشكل مش بشري، مشبوه.
- `ip_h` متكررة بين فايزين مختلفين يعني نفس المكان (ممكن يكون بيت واحد، راجعه بنفسك).

**رفض نتيجة مشبوهة:** الفايز المرفوض بيتشال من اللوحة، والجولة بتتفتح تاني للباقيين (طالما خميس الجاي لسه ما جاش).
```sql
UPDATE contest_scores SET status='rejected' WHERE contest_id=1 AND pid='ID_HERE';
UPDATE players SET banned=1 WHERE id='ID_HERE';   -- حظر الحساب (بيتلغي دخوله فوراً)
```
السيرفر أصلاً مش بيقبل أكتر من حوالي 9 تسبيحات في الثانية، فأسرع فوز ممكن حوالي دقيقتين.

## الهدف اليومي (v8)
هدف تسبيح لكل يوم على عدّاد الصفحة الرئيسية (مش المسابقة). بيظهر تحت لوحة «الأعلى» بعنوان «الهدف اليومي».

**التشغيل (مرة واحدة):** شغّل `migrate-v8.sql` في D1 Console وأعد النشر. لو ما شغّلتوش الموقع بيكمّل عادي من غير القسم ده (ولوحة الأدمن بتقولك تشغّله).

**إزاي بيشتغل:**
- أول طلب في اليوم بيختار هدف عشوائي بين **3000 و5000** (المدى بتغيّره من اللوحة)، ويفضل ثابت لكل الناس لحد آخر اليوم.
- كل لاعب بيتسجّل عدّه اليومي على السيرفر مع كل مزامنة. أول ما يبلغ الهدف بيتسجّل اسمه بوقت وصوله، حتى لو بعد ما بلغه كمّل تسبيح ما بيتغيّرش وقته.
- الصفحة بتعرض **أول 3 بس** بالترتيب مع وقت وصول كل واحد. بيفضلوا ظاهرين لحد نهاية اليوم، وبعدها يجي هدف جديد وقايمة فاضية. اللاعب شايف تقدّمه هو كمان (شريط + «تقدّمك اليوم: X من Y»)، واسمه بيتلوّن في القايمة لو هو من الأول 3.
- **حدود اليوم** بتوقيت القاهرة للكل (علشان الهدف والأسماء يتجددوا في نفس اللحظة). لو عاوز بلد تانية غيّر `D_TZ` في أول قسم الهدف اليومي في `functions/api/[[route]].js` (ومعاه `D_MIN` و`D_MAX` للمدى الافتراضي).
- اللاعب المحظور بيختفي من القايمة العامة، واللي اسمه فاضي مش بيظهر.

**التحكم من لوحة الأدمن (تبويب «اليومي»):**
- **تحديد هدف اليوم:** اكتب رقم (من 10 لـ 100000) واضغط «تطبيق». أو «عشوائي جديد» بيختار رقم جديد من المدى.
- **المدى:** أقل وأعلى هدف عشوائي. بيتطبّق من الهدف العشوائي الجاي (يوم جديد أو زر «عشوائي جديد»)، مش على هدف النهاردة.
- **تشغيل/إيقاف:** لو وقفته القسم بيختفي من الموقع، والتسبيح العادي بيكمّل طبيعي.
- **قايمة من بلغوا الهدف اليوم** (آخر 30) مع زر **حظر** لو شكيت في حد (نفس حظر تبويب المتسابقين: بيخرّجه ويخفيه).
- تغيير الهدف مش بيشيل أسماء اللي وصلوا قبله. لو نزّلت الهدف تحت عدّاد لاعب لسه ما اتسجّلش، بيتسجّل وصوله بوقت آخر تسبيحة ليه.

**ملحوظة أمان:** الهدف بيتحسب من نفس مزامنة التسبيح العادية (لحسابات جوجل بس، شوف «الأمان v11» تحت). السقف تراكمي: 12 تسبيحة في الثانية كمتوسط، ورصيد أقصاه دقيقة (720) لو كان ساكت. يعني هدف 3000 محتاج سكربت حوالي 4 دقايق على الأقل، مش ثواني. لو لقيت حد مشبوه استخدم زر «حظر» من التبويب (الحظر بيثبت لأن الحساب جوجل). لو عاوز سرعة أقل للهدف اليومي غيّر `SYNC_RATE` في أول الملف.

## الأمان (v11)
- **التسبيح على السيرفر لحسابات جوجل بس.** الترتيب العام وترتيب الغرف والهدف اليومي بيعرضوا حسابات جوجل بس. اللي بيسبّح من غير دخول عدّه بيفضل على جهازه ومحفوظ، ولما يسجّل دخوله بيتزامن. `/api/join` بقى بيرد 403 (مفيش حسابات من غير جوجل). **لحد ما تفعّل دخول جوجل (`GOOGLE_CLIENT_ID` هنا وفي Cloudflare) الترتيب والهدف اليومي هيبقوا فاضيين.**
- **سقف السرعة تراكمي** (`SYNC_RATE` و`SYNC_CREDIT` في `functions/api/[[route]].js`): قبل كده كل طلب كان بياخد +60 مجاناً، فسكربت كان يوصل لهدف اليوم في ثواني. دلوقتي الرصيد بيتحسب من آخر لحظة اتصرف منها، وطلبين متوازيين ما بياخدوش نفس الرصيد.
- **لاعب قديم (من غير جوجل) لما يسجّل دخوله** عدّه بيتنقل بحد أقصى `MERGE_CAP` (5000)، علشان أي عدّ متلاعب فيه قبل الإصلاح ما يتنقلش.
- **لاعب وصل الهدف بعد الفايز** والفايز اتستبعد: السيرفر بيحسم له الفوز تلقائياً (قبل كده كان بيتعلّق).
- **`migrate.js`**: بيقبل بيانات الانتقال بس لو مفيش حساب على الجهاز، وبيتحقق من القيم. تقدر تحذفه (وسطر `<script>` بتاعه في `index.html`) بعد ما الناس تخلص انتقالها من الدومين القديم.
- **`.gitignore`**: بيمنع رفع `.dev.vars` والأسرار على GitHub لما تشغّل `upload.bat`.
- **من خارج الكود (إعدادات Cloudflare):** Rate Limiting rule على `/api/*`، وCloudflare Access على `/admin.html` و`/api/admin/*`، وراجع حصة الخطة المجانية (Workers: 100 ألف طلب يومياً، D1: 100 ألف صف مكتوب يومياً) قبل أول خميس.


## نسخ احتياطي يومي لقاعدة البيانات (v10)
الملف `.github/workflows/backup.yml` بيصدّر قاعدة D1 كل يوم الساعة 01:00 UTC، بيشفّرها (AES-256) وبيحفظها كـ Artifact في GitHub لمدة 30 يوم. التشفير ضروري لأن القاعدة فيها إيميلات اللاعبين.

**الإعداد (مرة واحدة):** في GitHub > Settings > Secrets and variables > Actions أضف 3 Secrets:
- `CLOUDFLARE_API_TOKEN`: من Cloudflare > My Profile > API Tokens > Create Token (Custom) بصلاحية **Account > D1 > Edit**.
- `CLOUDFLARE_ACCOUNT_ID`: من صفحة Workers & Pages (الـ Account ID على اليمين).
- `BACKUP_PASSPHRASE`: كلمة سر طويلة عشوائية للتشفير. **احفظها في مكان تاني**، من غيرها النسخ مش هتتفتح.

بعدها من تبويب Actions شغّل «D1 Backup» يدوياً (Run workflow) مرة للتجربة، وتأكد إنها خضرا.

**تحميل نسخة وفكّها:**
```
openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in wzaker-2026-11-21.sql.enc -out backup.sql
```
**الاسترجاع** (على قاعدة فاضية أو جديدة، بعد ما تتأكد من الملف):
```
npx wrangler d1 execute wzaker --remote --file=backup.sql
```
ملاحظات: التصدير بيقفل الكتابة على القاعدة لحظات (يهم لو القاعدة كبيرة). GitHub بيوقف الـ workflows المجدولة بعد 60 يوم من عدم نشاط المستودع، فلو وقفت ادخل Actions وفعّلها. وD1 فيه كمان Time Travel (استرجاع لنقطة زمنية) بمدة بتختلف حسب الخطة، وده شبكة أمان إضافية مش بديل عن النسخ.

## العدّاد العالمي (v10)
سطر «ذكرنا الله معاً X مرة» تحت الإحصائيات. الرقم بيتحفظ في `settings` تحت `taps_total` ويزيد مع كل مزامنة، وأول نبضة بيتحسب من مجموع `players.total`، فمفيش migration. بيحسب تسبيحات حسابات جوجل بس (اللي بتتزامن مع السيرفر). لو عايز تصفّره: `DELETE FROM settings WHERE k='taps_total';` وهيتحسب تاني من المجموع.
