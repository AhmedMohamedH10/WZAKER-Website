# الاختبارات (tests/)

اختبارات آلية للسيرفر (`functions/api/[[route]].js`) بتشتغل محليًا على جهازك، على قاعدة بيانات مؤقتة في الذاكرة. مش بتلمس الموقع ولا قاعدة البيانات الحقيقية ولا محتاجة أي مفاتيح.

## التشغيل
1. نزّل Node.js نسخة 22.5 أو أحدث من https://nodejs.org
2. في فولدر المشروع نفّذ:
   ```
   node --test
   ```
   (أو `npm test` — نفس الأمر)
3. المفروض تشوف `pass 23` و `fail 0`.

## بتغطي إيه
- `validation.test.mjs` — تنضيف الأسماء، منع انتحال صفة الموقع، التحقق من المعرّفات والصور.
- `timezone.test.mjs` — مواعيد الخميس 10 مساءً بتوقيت كل بلد، بما فيها التوقيت الصيفي في مصر، وبداية اليوم للهدف اليومي.
- `turnstile.test.mjs` — منطق التحقق من الإنسان: متخطّى لما يكون مقفول، وبيرفض صح لما يتفعّل (بردّ مُحاكى من Cloudflare).
- `ratelimit.test.mjs` — تحديد معدل الطلبات: حدود كل مجموعة، العزل بين الزائرين على نفس الشبكة، وإن الأدمن بيتحدد بالـ IP.
- `api.test.mjs` — الـ API نفسه على قاعدة SQLite مؤقتة: حماية CSRF، النبض والإحصائيات، الجلسات (السليم/المعدّل/المحظور)، اختيار الاسم، سقف سرعة التسبيح، قفل لوحة الأدمن بعد 5 محاولات غلط، ودورة مسابقة كاملة (بداية يدوية ← مشاركة ← فوز واحد بس ← وسيلة التواصل ← قفل الجولة).
- `d1-shim.mjs` — بديل محلي لواجهة قاعدة D1 وقت الاختبار. لو نسخة Node أقدم ومفيهاش `node:sqlite`، اختبارات `api.test.mjs` بتتخطّى لوحدها برسالة وباقي الاختبارات بتشتغل.

## ملحوظة
ملف `package.json` في جذر المشروع موجود علشان Node يفهم إن الملفات modules وقت الاختبار بس. مالوش أي تأثير على الموقع أو على النشر.
